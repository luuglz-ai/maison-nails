# MAISON NAILS

### Nail Care & Beauty

Maison Nails es un sitio web One-Page desarrollado como proyecto final de la Diplomatura en Programación Web Full Stack de la UTN.

El proyecto representa un estudio de manicura y estética, con una propuesta visual inspirada en el lujo editorial, combinando una estética minimalista, elegante y moderna.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox
- Responsive Design
- Git y GitHub

## Características del proyecto

- Diseño adaptable a celulares, tablets y computadoras.
- Menú de navegación responsive.
- Presentación de servicios de manicura y estética.
- Galería de ocho fotografías.
- Formulario de reserva con validación de campos.
- Calendario que impide seleccionar fechas anteriores al día actual.
- Sección de suscripción a novedades (Maison Club).
- Apartado Mi cuenta.

## Estructura del sitio

El sitio incluye las siguientes secciones principales:

1. Inicio
2. Servicios
3. Galería
4. Reserva tu turno
5. Contacto

## Objetivo

Aplicar los conocimientos adquiridos durante la diplomatura mediante el desarrollo de un sitio web funcional, responsive y visualmente profesional.
